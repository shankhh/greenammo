# 🌿 GREENAMMO Website Management Guide for Non-Technical Staff

Welcome to the **GREENAMMO Website Content Management Guide**! 

You can manage website navigation menus, page copy, text headlines, image captions, and **publish new regional project milestones** directly from the **WordPress Admin Dashboard** without touching any code.

---

## 🔑 1. Logging into WordPress Admin

1. Open your web browser and go to:
   👉 **`https://cms.greenammo.in/wp-admin`**
2. Log in using your assigned username and password.

---

## 🧭 2. How to Add or Edit Navigation Menus

You can add new pages, change link names, reorder menu items, or create dropdown sub-menus for any of the 3 website divisions:
- **`GreenAmmoGroup`** (Group Portal main navbar)
- **`Trust`** (GREENAMMO Trust NGO navbar)
- **`Solutions`** (GREENAMMO Solutions Commercial navbar)

### Steps:
1. In the left sidebar, go to **Appearance → Menus**.
2. At the top of the page, select the menu you want to edit (`GreenAmmoGroup`, `Trust`, or `Solutions`) and click **Select**.
3. **Add a Link**: Use **Custom Links** or **Pages** on the left, type the link title and URL, then click **Add to Menu**.
4. **Reorder / Create Dropdowns**: Drag items up or down to reorder them. Drag an item slightly to the right to nest it as a sub-item (dropdown).
5. Click the blue **Save Menu** button at the top right. Changes update live on `greenammo.in` instantly!

---

## 🚀 3. How to Publish a New Regional Project Milestone (Zero-Code)

You can add new project milestone cards to any state page (`Meghalaya`, `West Bengal`, `Assam`, `Goa`, `Himachal Pradesh`, `Arunachal Pradesh`, `Nepal`, `Odisha`, `Tamil Nadu`) directly from WordPress.

### Steps:
1. In the left sidebar, go to **Projects → Add New**.
2. **Title**: Enter the milestone title (e.g., *"Shillong Waste Tapping Drive 2026"*).
3. **Description Copy**: Type your project story, highlights, or bullet points in the main WordPress post editor box.
4. **Attach Photos**: Scroll down to **Project Settings** and attach photos using **Image 1**, **Image 2**, **Image 3**, **Image 4**.
5. **Select Region (Tagging)**:
   - Select the target region from the **Region** dropdown (e.g. `Meghalaya`, `West Bengal`, `Assam`, `Goa`, etc.).
6. Click the blue **Publish** button.

✨ **Result**: A brand-new milestone card, formatted text copy, and photo gallery with popup zoom will automatically render on the live region page!

---

## 🖼️ 4. How to Add Captions & Descriptions to Photos

Images in project galleries display interactive captions below the photo card and inside full-screen image popups.

### Steps:
1. In the left sidebar, click **Media → Library**.
2. Click on the image you want to edit.
3. Fill in the **Caption** field (e.g., *"Community waste management workshop in Shillong"*).
4. Changes save automatically when you click outside the text box!

---

## 📝 5. How to Edit Page Text and Copy

You can update headlines, team bios, mission statements, and section copy directly.

### Steps:
1. In the left sidebar, click **Pages → All Pages**.
2. Click on the page you want to update (e.g., `About Us`, `Join Us`, or `Donate`).
3. Use the visual text editor to type or format your content.
4. Click the blue **Update** button on the top right to publish your changes.

---

## ⚡ Frequently Asked Questions (FAQ)

### How fast do my changes show up on the live website (`greenammo.in`)?
The website uses a Stale-While-Revalidate (SWR) caching engine. Changes updated in WordPress Admin will reflect live instantly on the next page view or refresh.

### What if I accidentally delete a menu link or page?
Don't worry! The core website has built-in safety defaults. Deleting a link in WordPress will default back to standard baseline navigation without breaking the site layout.

### Need Help?
Contact the GREENAMMO tech team for assistance or account access resets.
