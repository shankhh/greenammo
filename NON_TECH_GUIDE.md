# 🌿 GREENAMMO Website Management Guide for Non-Technical Staff

Welcome to the **GREENAMMO Website Content Management Guide**! 

You can manage website navigation menus, page copy, text headlines, and image captions directly from the **WordPress Admin Dashboard** without touching any code.

---

## 🔑 1. Logging into WordPress Admin

1. Open your web browser and go to:
   👉 **`https://cms.greenammo.in/wp-admin`**
2. Log in using your assigned username and password.

---

## 🧭 2. How to Add or Edit Navigation Menus

You can add new pages, change link names, reorder menu items, or create dropdown sub-menus for any of the 3 website divisions:
- **`GREENAMMO Group Navigation`** (`group-nav`)
- **`GREENAMMO Trust Navigation`** (`trust-nav`)
- **`GREENAMMO Solutions Navigation`** (`solutions-nav`)

### Steps:
1. In the left sidebar, go to **Appearance → Menus**.
2. At the top of the page, choose the menu you want to edit from the dropdown list and click **Select**.
3. **Add a Link**: Use the **Custom Links** or **Pages** box on the left, type the link title and URL, then click **Add to Menu**.
4. **Reorder / Create Dropdowns**: Drag and drop items up or down. Drag an item slightly to the right to make it a sub-item (dropdown).
5. Click the blue **Save Menu** button at the top right.

---

## 🖼️ 3. How to Add Captions and Descriptions to Images

Images in project galleries and photo showcases can display captions below the image card and inside full-screen image popups.

### Steps:
1. In the left sidebar, click **Media → Library**.
2. Click on the image you want to edit.
3. On the right panel, fill in the following fields:
   - **Caption**: The public text displayed under the photo (e.g., *"Community waste management workshop in Shillong"*).
   - **Alt Text**: A short description for accessibility (e.g., *"GREENAMMO volunteers planting saplings"*).
4. Changes save automatically when you click outside the text box!

---

## 📝 4. How to Edit Page Text and Copy

You can update headlines, team bios, mission statements, and section copy directly.

### Steps:
1. In the left sidebar, click **Pages → All Pages**.
2. Click on the page you want to update (e.g., `About Us`, `Join Us`, or `Donate`).
3. Use the visual text editor to type or format your content.
4. Click the blue **Update** button on the top right to publish your changes.

---

## 📂 5. Managing Regional Project Galleries

To update gallery images for state initiatives (Meghalaya, Assam, West Bengal, Goa, etc.):

1. In the left sidebar, click **Projects → All Projects**.
2. Select the regional project you wish to update (e.g., *Meghalaya Eco-Tourism*).
3. Upload or select images under the gallery custom fields.
4. Click **Update**.

---

## ⚡ Frequently Asked Questions (FAQ)

### How fast do my changes show up on the live website (`greenammo.in`)?
The website uses an instant caching engine. Changes updated in WordPress Admin will appear on the live site on the next page view or refresh.

### What if I accidentally delete a menu link or page?
Don't worry! The core website has built-in safety defaults. Deleting a link in WordPress will not break the website structure.

### Need Help?
Contact the GREENAMMO tech team for assistance or account access resets.
